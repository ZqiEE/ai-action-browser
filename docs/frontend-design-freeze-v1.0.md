# Frontend Design Freeze v1.0

状态：Frozen for prototype

## 1. 产品体验定义

AI Action Browser 不是聊天机器人、企业后台或营销网站。它是一个面向全球普通消费者的浏览器入口：用户表达目标，系统负责搜索、比较和准备，关键操作前由用户明确确认。

核心体验：

> Say it once. Confirm once. Done.

产品应给人的第一印象：

- 像普通浏览器一样容易理解；
- 比普通搜索更能完成事情；
- 视觉安静，不与网页内容争夺注意力；
- 过程可见，关键动作可控；
- 商业内容透明，不影响自然推荐。

## 2. 最终视觉方向

**Essential Utility with Consumer Warmth**

中文定义：安静、清楚、可靠的消费级行动工具。

### 必须具备

- 以黑白灰为主体；
- 清晰的排版和边界；
- 低装饰、低噪音；
- 适度留白但不牺牲决策信息；
- 微圆角而非大面积胶囊；
- 只有浮层和来源面板使用轻阴影；
- 动效表达状态变化，不制造表演感。

### 禁止出现

- AI 紫色渐变；
- 发光、玻璃拟态和背景模糊；
- 机器人、大脑、魔法棒、星星和拟人化“思考”动画；
- 大面积品牌色卡片；
- 用锁或盾牌暗示整体安全；
- 将极高风险确认设计成 Modal、Scrim 或 Bottom Sheet；
- 长按、滑动作为默认高风险确认机制。

## 3. 颜色决定

采用 **Monochrome Core + Reserved Teal Accent**。

### 结构色

- 浅色模式以白、浅灰、近黑文字构成；
- 深色模式以深灰黑、略亮表面、灰白文字构成；
- 主要操作采用黑白反色；
- 页面 95% 以上由中性色承担。

### 辅助品牌色

- 浅色模式 Accent：`#00665E`；
- 深色模式 Accent：`#55BDB2`；
- 仅用于 Focus、Active、Progress、当前任务标记和少量品牌识别。

不得用于：

- 全部主按钮；
- 成功状态；
- 商家可信；
- 自然推荐第一名；
- Cashback；
- Sponsored 内容。

### 主要按钮

- 浅色：近黑背景、白色文字；
- 深色：灰白背景、近黑文字；
- 危险按钮仅用于真正破坏性且不可逆的操作。

## 4. 排版决定

正文优先使用平台系统字体。品牌字标未来可独立设计，但不得影响加载、多语言和可读性。

- 页面标题：桌面 30–32px / 移动 24–26px，600；
- 区块标题：桌面 20px / 移动 18px，600；
- 组件标题：16–18px，500–600；
- 正文：桌面 15–16px / 移动 16px，400；
- 辅助信息：14px，400；
- 时间戳和短标签：最低 12–13px；
- 商业披露、隐私和数据共享：不得低于 14px；
- 价格：20–28px，600–700，使用 tabular numbers。

支持 200% 文字缩放，不得出现截断、覆盖或横向滚动。

## 5. 首页决定

首页是打开即用的产品入口，不是营销首页。

### 首次访问

- 左上角：低调文字标识；
- 右上角：弱化的登录入口；
- 中央偏上：一句短标题；
- 中央：Omniprompt；
- 输入框下方：少量示例任务；
- 页面底部：免费、无需注册、关键操作确认和隐私说明。

标题使用：

> What do you want to find or get done?

### 返回用户

- 标题可缩小；
- 输入框下方展示最近一项未完成任务和少量最近任务；
- 不形成 Dashboard；
- Omniprompt 仍是绝对主入口。

### 移动端

- 默认不贴底；
- 标题位于页面上半区；
- 输入框位于中部偏下；
- 键盘出现后标题收缩或隐藏，输入框上移并停靠键盘上方；
- 任务开始后 Omniprompt 吸顶成为任务控制栏。

## 6. Omniprompt 决定

采用 **Dynamic Action Block**，但不使用彩色跑马灯、呼吸或星星图标。

### 结构

- 左侧：当前行为名称与简单图标；
- 中间：自然语言输入区；
- 右侧：语音、图片、附件；
- 下方：意图建议、状态文字或控制；
- 最底部：2px 状态线。

### 行为

- 默认行为永远是 Search；
- 系统可以建议 Compare 或 Prepare；
- 系统不得秘密自动切换；
- 用户通过建议项明确接受切换；
- 输入内容始终保持可见和可编辑，执行时可暂时只读；
- 执行中右侧提供 Stop。

### 状态表达

- 默认：中性边框；
- Focus：辅助湖水绿 Focus Ring；
- Compare 建议：文字和浅层 Accent，不使用紫色；
- Running：状态文字 + 2px 进度线；
- Awaiting confirmation：琥珀色状态；
- Error：红色边框和就地说明；
- Complete：中性完成文案，不使用全屏绿色或大对勾。

执行状态示例：

> Comparing prices · 8 of 12 stores checked

## 7. 结果展开决定

- Omniprompt 任务启动后吸顶；
- 结果使用稳定的渐进式呈现；
- 立即展示固定尺寸框架和已确认摘要；
- 后续模块填入预留区域；
- 图片必须预留宽高比；
- 不等待全部结果完成后一次性显示；
- 不使用聊天气泡；
- 不进行逐卡片表演式动画；
- reduced-motion 下直接切换。

## 8. 购物比较页决定

### 桌面

- 顶部：用户条件与 Edit；
- 主内容约 65%；
- 决策侧栏约 35%；
- 一项主推荐；
- 两项紧凑备选；
- 右侧显示最终总价、关键差异和 Prepare；
- 来源从右侧独立 Side Panel 展开；
- Sponsored 永远位于自然内容之后。

### 移动

- 主推荐置顶；
- 备选使用紧凑列表或关键差异表，不堆叠大型卡片；
- 来源使用全屏子页面或平台合适的 Sheet；
- 底部固定总价和 Prepare；
- Sponsored 位于自然结果之后且允许隐藏。

### 推荐透明度

主推荐必须显示：

- 为什么更适合用户；
- 两至三个关键优势；
- 至少一个必须接受的缺点；
- 最终总价；
- 配送、退货、保修、商家；
- 来源与更新时间；
- 信息冲突和不确定性。

## 9. 来源决定

来源引用不可仅写 `Source [1]`。

来源面板必须展示：

- 来源名称；
- 支持的具体结论；
- 获取时间；
- 来源类型；
- 是否可能过期；
- 是否存在冲突；
- 原始网页入口。

页面内容、商家信息、评测和用户评论必须区分类型。冲突信息不得被隐藏。

## 10. Sponsored 与商业内容决定

商业内容不使用大面积紫色、优惠券虚线或高饱和品牌色。

- 中性灰或灰蓝表面；
- 普通实线边框；
- 明确写 `Sponsored offer`；
- 正文至少 14px；
- Logo 保持可识别，但尺寸严格限制；
- 商家不得自定义卡片背景；
- Cashback 使用克制琥珀色；
- 用户可隐藏；
- 不得替换主推荐；
- 不得比自然结果更醒目；
- 推荐计算接口不得接收出价、佣金、合作等级或营收信息。

## 11. 极高风险确认决定

付款、提交身份信息、发送、签署、公开发布、永久删除使用独立全屏页面。

### 禁止

- Modal；
- Scrim；
- 背景模糊；
- 480px 收据弹窗；
- Bottom Sheet；
- 大绿色锁；
- 虚假的 Verified Merchant；
- 默认长按；
- 默认滑动确认。

### 页面顺序

1. Destination；
2. Action summary；
3. Order；
4. Delivery；
5. Payment；
6. Data sharing；
7. Reversibility；
8. Commercial disclosure；
9. Edit、Cancel 和 Confirm。

点击 Confirm 后调用系统身份验证，如 Passkey、Face ID、Touch ID 或 Windows Hello。系统身份验证成功后才执行。

### 宽度

- 桌面：680–760px 的页面内容列；
- 移动：全宽单列；
- 移动底部可以固定操作栏，但页面本身仍是独立全屏页面。

## 12. 动效决定

- 一般状态变化：120–240ms；
- 不使用 Bounce、戏剧化下坠或放大；
- 不使用无限循环的装饰性 Loading；
- 不使用沿边框奔跑的动画；
- 进度优先显示真实步骤和已完成数量；
- reduced-motion 下禁用位移和淡入。

## 13. 十条不可违反原则

1. 普通用户打开后必须知道可以搜索和完成事情。
2. Search 默认保留，AI 不得秘密切换行为。
3. 决策信息优先于装饰，但不得牺牲可读性和触摸安全。
4. 品牌色、成功色、安全信息和商业内容不得语义混淆。
5. 每项推荐必须展示理由、证据和至少一个 Trade-off。
6. 价格、来源、更新时间和冲突必须可追溯。
7. Sponsored 不得影响自然推荐排序或购买最佳位置。
8. 高风险操作必须完整预览、明确确认并匹配风险等级进行系统验证。
9. 浏览器界面不得与网页内容争夺视觉注意力。
10. 失败时优雅降级到普通搜索或可恢复步骤，不使用夸张插画和拟人化错误。
