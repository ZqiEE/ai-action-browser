## Trust questions

Ask after the participant completes the flow:

1. What did the product recommend and why?
2. What information was uncertain or potentially out of date?
3. Which content, if any, was paid or Sponsored?
4. What would happen after pressing Prepare?
5. Did any real payment or purchase occur?
6. Would you use this instead of starting with a conventional search engine? Why?

## Investor-ready summary

Report only measured results:

- number of unique participants;
- number of sessions;
- completion rate;
- recommendation-comprehension rate;
- Sponsored-identification rate;
- merchant-handoff rate;
- stated repeat-use intent;
- average and p95 total task cost;
- average model calls per task;
- cache and unchanged-evidence reuse rate;
- strongest commercial signal;
- main reason users abandoned or distrusted the flow.
